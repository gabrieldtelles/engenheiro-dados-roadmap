# SQL Analytics e dbt-core

## 📋 Sobre

**Intensivo de SQL e Analytics Engineering** projetado para equipar habilidades avançadas de engenharia de dados e análise de dados. Cobre desde SQL básico até transformações complexas com dbt-core.

**Objetivo Educacional**: Dominar SQL avançado para analytics e aprender a usar dbt-core para transformações de dados profissionais.
